Política de privacidade do Corteszinsbr Drive

O Corteszinsbr Drive é uma integração de uso pessoal. O editor recebe a URL pública de um clipe e gera arquivos de vídeo e revisão no GitHub Actions.

Acesso ao Google Drive

Com a autorização do responsável, o workflow usa o escopo OAuth drive.file. Ele consulta a pasta selecionada e as subpastas e arquivos que cria para entregar os vídeos e seus arquivos de revisão. Os dados acessados no Google Drive são usados para essa entrega e sua verificação.

Armazenamento e compartilhamento

A configuração OAuth é armazenada como segredo do repositório público do editor e é fornecida ao GitHub Actions para autenticar o envio. Os arquivos enviados ficam sujeitos às permissões da pasta do Google Drive. O workflow também disponibiliza como artefatos públicos, por sete dias, os resultados de edição gerados no GitHub Actions a partir do clipe público. A integração não publica em redes sociais.

Revogação e contato

O responsável pode revogar o acesso pela Conta do Google e remover o segredo no GitHub. Os arquivos enviados podem ser gerenciados diretamente no Drive.

Para dúvidas sobre esta política, entre em contato com o responsável pelo projeto no GitHub.
